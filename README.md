📚 Project Overview

Smart MCQ and Quiz Generator is an intelligent tool designed to simplify the process of creating and taking quizzes. By uploading documents in .txt, .docx, or .pdf formats, the system automatically analyzes the content and generates multiple choice questions (MCQs) from it. Users can then choose to generate a complete quiz from the questions, take the quiz within the platform, and view their results instantly.

This project leverages Natural Language Processing (NLP) techniques to understand and extract key information from documents, ensuring relevant and context-aware MCQs.

✨ Features

📂 Upload Documents: Supports .txt, .docx, and .pdf file formats.

🧠 Automatic MCQ Generation: Uses NLP to generate quality MCQs from the uploaded content.

📝 Quiz Generation: Option to compile MCQs into a complete quiz.

🧪 Take the Quiz: Interactive quiz-taking interface for users.

📊 View Results: Displays detailed results after completing the quiz.
